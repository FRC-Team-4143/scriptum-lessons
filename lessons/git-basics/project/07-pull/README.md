# 7. Pull

While you were working, a teammate pushed a new commit to `develop` on
`origin`. Your copy doesn't have it yet. Getting other people's work is
called **pulling**.

## Task

1. Click the repository name in the bottom-left corner (just left of the
   branch name) and choose **07-pull**. The branch name beside it says
   `develop`.
2. Bring your copy up to date with `origin`: in Source Control, scroll to the
   **07-pull** row and click its **...** menu. Choose **Pull, Push**, then
   **Pull**.

(Pull is a download of the new commits followed by a merge that brings them
in.) Open `Schedule.txt` afterwards to see
what your teammate added. Run **Verify** when you're done.

## You're done when

Your `develop` has the same latest commit as `develop` on `origin`.
