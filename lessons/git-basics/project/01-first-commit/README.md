# 1. First Commit

This folder is already a git repository with one commit in it (you will
see it in the **Graph** in Source Control).

## Task

1. Open `roster.txt` and add your name on its own line.
2. Save, then open Source Control. Stage the change with the **+** next to
   `roster.txt`, write a real commit message (not "update" or "wip" — say what
   you did, e.g. `Add my name to the roster`) and press **Commit**.

That's it. Click **Checkpoints** in the top bar and run **Verify** when
you're done.

## You're done when

The **Graph** in Source Control shows a new commit on top of the original
one, your name is in `roster.txt`, and the Changes list is empty (nothing
left unstaged).
