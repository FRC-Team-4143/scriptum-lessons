# 1. First Commit

This folder is already a git repository with one commit in it (`git log`
to see it).

## Task

1. Open `roster.txt` and add your name on its own line.
2. Stage and commit the change, with a real commit message (not "update" or
   "wip" — say what you did, e.g. `Add my name to the roster`).

That's it. Click **Checkpoints** in the top bar and run **Verify** when
you're done.

## You're done when

`git log` shows a new commit on top of the original one, your name is in
`roster.txt`, and `git status` says the working tree is clean (nothing left
unstaged).
